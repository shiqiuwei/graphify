# 从源码目录安装 Graphify（Windows / PowerShell）

本文记录两套教程：

1. 不使用 `uv`，从当前源码目录安装 `graphify`
2. 使用 `uv`，从当前源码目录安装 `graphify`

适用环境：

- 当前源码目录：`E:\graphify`
- Shell：PowerShell
- 目标：安装后 `graphify` 可全局使用
- 目标：尽量启用仓库 `.[all]` 对应的全部 Python 侧可选功能

## 先说结论

如果你希望 `.[all]` 里的 `graspologic` 也能装上并用于 Leiden 聚类，建议使用 **Python 3.12**。

原因：

- 仓库在 `pyproject.toml` 中把 `graspologic` 限制为 `python_version < '3.13'`
- 当前如果使用 Python 3.13，`.[all]` 安装时不会包含 `graspologic`

## 仓库关键信息

- 包名：`graphifyy`
- 命令名：`graphify`
- `.[all]`：仓库定义的可选依赖全集

对应位置：

- `E:\graphify\pyproject.toml`

## 教程一：不使用 uv，从源码目录安装

这套方式使用系统安装的 Python 3.12 和 `pip`。

### 1. 安装 Python 3.12

推荐在 Windows 上使用：

```powershell
winget install Python.Python.3.12
```

安装完成后，确认 `py` 启动器能找到 3.12：

```powershell
py -3.12 --version
```

如果这里仍然报错，先执行：

```powershell
py --list
```

确认机器上是否已经存在可被 `py` 识别的 Python 3.12。

### 2. 进入源码目录

```powershell
Set-Location E:\graphify
```

### 3. 升级 Python 3.12 下的安装工具

```powershell
py -3.12 -m pip install --user -U pip setuptools wheel
```

### 4. 从当前源码目录安装 graphify

全功能安装：

```powershell
py -3.12 -m pip install --user -e ".[all]"
```

说明：

- `-e` 表示 editable，可编辑安装
- 安装后命令会直接使用当前源码目录
- 修改 `E:\graphify` 中的源码后，通常不需要重新安装

如果只想最小安装，可改用：

```powershell
py -3.12 -m pip install --user -e .
```

### 5. 让 graphify 在任意目录可用

如果安装完成后执行 `graphify --version` 提示找不到命令，先查 Python 3.12 的用户安装目录：

```powershell
py -3.12 -m site --user-base
```

假设输出为：

```text
C:\Users\你的用户名\AppData\Roaming\Python\Python312
```

则需要确保下面这个目录在 `PATH` 中：

```text
C:\Users\你的用户名\AppData\Roaming\Python\Python312\Scripts
```

更新完 `PATH` 后，关闭当前 PowerShell，重新打开一个新窗口。

### 6. 验证安装结果

```powershell
graphify --version
where graphify
py -3.12 -c "import graphify; print(graphify.__file__)"
```

如果你希望验证 `.[all]` 里的关键包都可导入，可执行：

```powershell
py -3.12 -c "import graphify,pypdf,markdownify,watchdog,graspologic,docx,openpyxl,faster_whisper,yt_dlp,matplotlib,openai,tiktoken,boto3,tree_sitter_sql,neo4j,mcp; print(graphify.__file__)"
```

### 7. 如果还要给 Codex 注册

```powershell
graphify install --platform codex
```

## 教程二：使用 uv，从源码目录安装

这套方式使用 `uv` 管理 Python 3.12，并把 `graphify` 安装成全局工具。

### 1. 确认 uv 已安装

```powershell
uv --version
```

如果还没安装，可执行：

```powershell
winget install astral-sh.uv
```

### 2. 进入源码目录

```powershell
Set-Location E:\graphify
```

### 3. 让 uv 安装 Python 3.12

```powershell
uv python install 3.12
```

### 4. 确认 uv 能找到 3.12

```powershell
uv python find 3.12
```

如果这一步能返回一个 Python 3.12 路径，说明后续可以继续。

### 5. 如果之前已经用 uv 装过 graphify，先卸掉旧工具环境

```powershell
uv tool uninstall graphify
```

### 6. 从当前源码目录安装 graphify

下面这条命令等价于“从源码目录安装，并尽量覆盖仓库 `.[all]` 里的可选依赖”：

```powershell
uv tool install --python 3.12 --editable . --force `
  --with mcp `
  --with neo4j `
  --with pypdf `
  --with markdownify `
  --with watchdog `
  --with graspologic `
  --with python-docx `
  --with openpyxl `
  --with faster-whisper `
  --with yt-dlp `
  --with matplotlib `
  --with openai `
  --with tiktoken `
  --with boto3 `
  --with tree-sitter-sql
```

说明：

- `--editable .` 表示直接使用当前源码目录
- `--python 3.12` 保证这套工具环境基于 Python 3.12
- 多个 `--with` 用来补齐仓库 `.[all]` 中对应的依赖

如果只想最小安装，可改用：

```powershell
uv tool install --python 3.12 --editable .
```

### 7. 让 graphify 在命令行里可见

如果安装完成后仍然找不到 `graphify`，执行：

```powershell
uv tool update-shell
```

然后关闭当前 PowerShell，重新打开一个新窗口。

### 8. 验证安装结果

```powershell
graphify --version
where graphify
uv tool list --show-python --show-with --show-paths
```

### 9. 如果还要给 Codex 注册

```powershell
graphify install --platform codex
```

## 哪些功能即使装了依赖也还需要额外条件

`.[all]` 只负责 Python 依赖，不代表所有功能立刻都能运行。

还需要额外条件的常见功能：

- `openai / gemini / kimi / ollama / bedrock`：需要对应 API Key 或本地服务
- Google Workspace：需要额外安装并登录 `gws`
- Neo4j push：需要可访问的 Neo4j 实例
- 视频转录：需要本机有足够的 CPU / 内存资源

---

## 选型建议

优先建议使用“教程二：使用 uv”：

- 更适合把 `graphify` 安装成全局可用命令
- 不容易污染系统 Python 环境
- 适合长期把当前源码目录当作可编辑工具来使用

如果你更熟悉传统 Python 工作流，或公司环境已经统一使用系统 Python + `pip`，就用“教程一：不使用 uv”。
